# viewer — 推定したネットワークをブラウザで見る (cosmos.gl)

`fast_bn` が出力したネットワークを [cosmos.gl](https://github.com/cosmosgl/graph)
(GPU で力学レイアウトを計算する WebGL グラフ) で対話的に表示するビューアです。
`figures/*.png` (matplotlib の静止画) に対して、**探索しながら確認する**ためのもの。

## 起動

```bash
python3 viewer/serve.py          # リポジトリ全体から推定済みネットワークを探して起動
```

ブラウザが開き、既定で `example_bulk/out` の学習網が表示されます (何も推定していない
場合は `example_bulk/run_all.sh` を 1〜2 分実行すれば確認用のネットワークができます)。
Python 標準ライブラリのみで動き、npm / ビルド / 外部通信は不要です
(cosmos.gl は `vendor/` に同梱)。

```bash
python3 viewer/serve.py --root my_analysis        # 特定の解析ディレクトリだけ
python3 viewer/serve.py --port 9000 --no-browser  # ポート指定 / 自動で開かない
python3 viewer/serve.py --select "example_sc/run_bbknn_binall/out::consensus"
python3 viewer/serve.py --list                    # 見つかったネットワークを一覧表示
```

サーバは `127.0.0.1` にのみ bind し、配信するのは `viewer/` 以下のファイルと
JSON API だけです (データファイルの内容は API 経由でのみ渡されます)。

## 何を読むか

ディレクトリを走査して、次の組み合わせを 1 つのネットワークとして扱います。

| 種類 | 構造 | 名前 | 付随ファイル (あれば自動で使う) |
| --- | --- | --- | --- |
| 学習網 | `edges.tsv` | `edges_named.tsv` | `edge_importance.tsv`, `eval_hc_edges.tsv` |
| コンセンサス網 | `integ_edges2.tsv` | `integ_edges_named.tsv` | `integ_edge_importance.tsv`, `integ_edges_score.tsv` (ブートストラップ確率), `eval_bs_edges.tsv` |

加えて `<run>/data/var_map.tsv` (変数総数) と `<run>/target_genes.txt` (注目遺伝子) を
見ます。**ノード名は `edges.tsv` と `edges_named.tsv` の行対応から復元**します
(`var_map.tsv` を作り直しても表示がずれない、という repo の約束と同じ)。
名前が食い違う場合は警告を出し、行対応を優先します。

## 画面

* **ネットワーク** — 見つかった網を切り替える (ディレクトリごとにグループ化)。
* **エッジの色・太さ** — `|ΔlogL|` / `|ΔBIC|` / `|ΔK2|` / `|ΔBDeu|` /
  `|平均ΔlogL/サンプル|` / `|標準偏差ΔlogL/サンプル|` (いずれも `visualize.py` と同じ
  **絶対値**)、**ブートストラップ確率**、**正解構造との判定** (TP / FP / FP_reversed / FN)、
  一律。重要度は桁が大きく違うので**順位で正規化**して色と太さに割り当てます。
* **表示するエッジ** — 「簡易」と「詳細」をトグルで切り替えます。
  * **簡易**: 色に使っている属性の上位 X% だけ表示 (密な網をざっと絞るため)。
    スライダの下に**その属性のヒストグラム**が出るので、分布を見ながら決められます。
  * **詳細**: **複数のメトリックの閾値を組み合わせて**絞り込みます。条件を何本でも
    追加でき、`AND` (すべて満たす) / `OR` (いずれか満たす) を選べます。1 条件は
    「属性 × 順位 or 値 × ≥ or ≤ × しきい値」で、例えば
    「`|ΔlogL|` 上位 30% **かつ** ブートストラップ確率 ≥ 0.8」のような指定ができます。
    * **順位** モード: 上位/下位 X% (桁の違う重要度を横並びで扱えます)。
    * **値** モード: 絶対値でのしきい値 (数値入力とスライダの両方で指定可)。
    * どちらのモードでも、判定は最終的に**値**で行います。順位で切ると同じ値の
      エッジが恣意的に分断されるため、「上位 30%」はその順位に対応する値を
      しきい値として使い、同値のエッジはまとめて通します (実際の本数は各条件の
      下に出ます)。
    * 判定 (`eval_*_edges.tsv` がある網) は TP / FP / FP_reversed / FN の
      チェックボックスで指定します (各状態の本数も表示)。学習網に無いエッジである
      `FN` は該当 0 になります。
    * 各条件に**ヒストグラム**・「その条件だけで何辺が該当するか」・属性の範囲を
      表示し、下部に組み合わせた結果 (`結果: 15 / 80 辺`) を出します。条件は左の
      チェックで一時的に無効化、`✕` で削除できます。
    * 値が無いエッジ (その網に重要度が無い等) は条件を通しません。条件に使える
      属性が無い網では「条件を作れません」と表示し、全エッジを表示します。
    * ネットワークを切り替えても、同じ属性がある限り条件は引き継がれます。
* **ヒストグラム (しきい値の決め方)** — 簡易・詳細のどちらでも、しきい値を決める
  ための分布を出します。

  | 要素 | 意味 |
  | --- | --- |
  | 灰色の棒 | その値の範囲にあるエッジの本数 (分布全体) |
  | 水色の棒 | そのうち条件を通る本数 (境界のビンは一部だけが重なります) |
  | 橙の線 | **そこにしきい値を置いたら何辺残るか** (累積)。単調なので、歪んだ分布でも「あと何本残るか」を読み取れます |
  | 赤い縦線 | いまのしきい値 |

  棒の上を**クリック / ドラッグするとしきい値をその位置に設定**できます
  (順位モードならその位置に対応する % に変換されます)。ホバーすると
  「ここを境にすると N 辺 (M%)」がツールチップに出ます。

  重要度の分布は強く歪む (大半が小さく、裾が長い) ため、線形の縦軸だと裾のビンが
  1px になって見えません。**「縦軸を対数に」**をチェックすると裾を見ながら
  しきい値を決められます (この設定はすべてのヒストグラムに効きます)。

* **ノード検索** — 遺伝子名の部分一致。クリックで選択・ズーム。
* **選択したノード** — 親 (→ このノード) と子 (このノード →) を属性値つきで一覧。
  クリックで隣のノードへ移動できます。周辺以外は暗くなります。
* **ノードの色** — 親のみ (source) / 中間 / 子のみ (sink) / 注目遺伝子。大きさ = 次数。
* **レイアウト** — 一時停止・全体表示 (`f`)・再配置、反発とエッジ長のスライダ。
  力学計算が落ち着くまで自動で全体表示に合わせます (自分でズームすると追従を止めます)。
* キーボード: `f` 全体表示 / `Space` 一時停止 / `Esc` 選択解除。

## 注意

矢印は「親 → 子」ですが、**観測データだけでは同じ独立性を表す DAG (マルコフ同値類) の
向きを決められません**。向きを因果の主張として読まないでください。判定 (TP/FP) の
色分けは、`compare_edges.py` / `evaluate_structure.py` を実行して
`eval_*_edges.tsv` がある網でのみ使えます。
